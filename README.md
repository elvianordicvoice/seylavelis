# SEYLA VELIS — официальный сайт

Готовый статический сайт для GitHub Pages. Сборка, Node.js и установка пакетов не нужны.

## Публикация

1. Распакуйте ZIP на компьютере.
2. Создайте репозиторий на GitHub (например, seyla-velis). Для бесплатного GitHub Pages используйте публичный репозиторий.
3. Загрузите содержимое архива в корень репозитория: index.html должен лежать рядом с README.md, а не во вложенной папке. Загрузите папку assets целиком. Не загружайте сам ZIP вместо файлов сайта.
4. Добавьте также .nojekyll (файл может быть скрыт файловым менеджером).
5. Сохраните файлы в ветке main.
6. Откройте Settings → Pages → Build and deployment → Source → Deploy from a branch.
7. Выберите main и /(root), затем Save.
8. Дождитесь публикации. Ссылка появится в Settings → Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Файлы

- index.html — содержимое, ссылки на площадки и контакт Gmail.
- style.css и refinements.css — дизайн, анимации и мобильная вёрстка.
- translations.js — 18 языков, английский по умолчанию.
- app.js — переключение языков, анимации и просмотр фотографий.
- assets/ — оптимизированные фотографии WebP.
- favicon.ico и apple-touch-icon.png — значки сайта.

Все локальные пути относительные: сайт работает и на пользовательском домене, и в подпапке GitHub Pages.
Шрифт Plus Jakarta Sans загружается из Google Fonts; при отсутствии сети используется системный шрифт.
Кнопка email открывает создание письма в Gmail; может потребоваться вход в Google.

После публикации при необходимости добавьте в head файла index.html метатег og:image с абсолютным публичным URL изображения вашего нового сайта (путь assets/release.webp), чтобы настроить картинку предпросмотра при отправке ссылки.
